# Demo product imagery

Placeholder photographs for the seed catalogue (`supabase/seed.sql`).
Replace them with your own product photos before launch — these show
generic hay, not the specific lots described on each listing.

These files are the **upload source** for `npm run seed:images`, which
pushes them into the `product-images` Supabase Storage bucket — that is
where the catalogue actually serves them from. A few also double as site
chrome (the homepage editorial photo and the About page).

All are public domain or permissively licensed, and were downloaded rather
than hotlinked, so nothing breaks when an upstream host changes.
